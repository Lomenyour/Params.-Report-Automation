# Варианты приложения

Состояние на 2026-10-26. Сборки и Excel-файлы остаются локальными и не
добавляются в Git.

| Роль | Путь | Состояние |
| --- | --- | --- |
| Тестовая | `dist_test/GTU_Report_Test/GTU_Report_Test.exe` | Обновляется первой через `build_gui.ps1`; содержит текущие изменения импорта и интерфейса. Для запуска нужна соседняя папка `_internal`. |
| Рабочая | `dist/GTU_Report/GTU_Report.exe` | Проверенная прежняя версия от 15.10.2026. Не заменять, пока тестовая не проверена пользователем. Папки `data` и `word_auto` рядом с ней сохранять. |
| Для коллеги | `app/delivery/GTU_Report_for_colleague.zip` | Пакет от 13.10.2026 с автономным EXE. Обновлять только после отдельного указания пользователя. Исходная сборка лежит в `app/dist/GTU_Report.exe`. |

Более старый `GTU_Report.zip` от 08.10.2026 перенесён в
`archive_builds/legacy_colleague_2026-10-08/` и не считается актуальным
пакетом для коллеги. `build_test/`, `build/` и `app/build/` — временные
файлы сборки. Прежняя тестовая сборка `dist_import/` перенесена целиком в
`archive_builds/2026-10-19_before_ui_fix/dist_import/`. Лишняя частичная
копия, образовавшаяся при первой попытке переноса, удалена.

Порядок обновления: собрать и проверить тестовую версию; после подтверждения
пользователя обновить рабочую; пакет для коллеги пересобрать только по
отдельному запросу. Скрипт `build_gui.ps1` пишет только в `dist_test/` и не
изменяет рабочую и коллегиальную сборки. Тестовая и рабочая сборки берут код
из `scr/`; автономная сборка для коллеги берёт код из `app/src/`. Правку
интерфейса в `app/src/` переносим при обновлении коллегиальной версии.

В тестовой версии явно выбирается расчёт готовой книги или обновление
данными датчиков. После расчёта результаты остаются в памяти и показываются
во вкладках; документы автоматически не сохраняются. Кнопки «Сформировать
Excel» и «Сформировать Word» доступны после успешного расчёта и предлагают
выбрать путь. По умолчанию оба документа сохраняются в общей папке
`data/output` корня проекта, включая запуск тестового EXE из `dist_test/`.
«Перерасчёт» повторно использует выбранные файлы и снова
открывает выбор периодов. Excel содержит листы «Данные», «Таблицы»,
«Графики» и видимые листы «Компрессор ПN» с данными периодных диаграмм.
На листе «Графики» размещаются редактируемая
диаграмма перепадов давления по референсу: стрелки и даты периодов, блоки
граничных параметров внутри графика, сетка и легенда снизу. Полные таблицы
номинальных точек совпадают с вкладкой «Параметры на границах» и остаются
под диаграммой. Кнопка «События графика» открывает ручной ввод дат и подписей
замен и ремонтов; список сохраняется отдельно по станции и ГТ. Word
формируется из того же успешного расчёта.

На листе «Графики» также есть общая диаграмма деградации ГТУ справа от
перепадов и отдельная диаграмма компрессора для каждого периода по TOP-1 ВНА.
Во всех диаграммах компрессора используется готовый `ηoi_Cprop` из расчёта.

26.10.2026 пользователь подтвердил работу тестовой версии и поручил
опубликовать её исходники и документацию в основной ветке GitHub.
Все 16 модулей из EXE от 23.10.2026 совпали с текущим кодом `scr/`;
17 автоматических тестов прошли. Публикация кода не заменяет локальные
бинарные сборки `dist/` и `app/dist/`. Шаблон
`word_auto/templates/template_mapped.docx` остаётся локальным; перед сборкой
на другом компьютере его нужно разместить отдельно.
