# Общая деградация ГТУ и ΔP — проверка 09.11.2026

## Изменения

- `degradation_chart.py` создаёт один видимый лист «Данные деградации ГТУ».
  Каждый период имеет собственный блок с датой, Nприв, bприв, КПД ГТУ,
  ВНА и номером исходной строки. Диаграмма ссылается на эти ячейки;
  копия точек в скрытых BJ:BN листа «Графики» удалена.
- Четыре параметра разделены на ряды по периодам. Нативные линейные
  тренды Excel используют только точки своего периода. Если для параметра
  нет двух конечных значений на разных датах, тренд не создаётся.
  Пропуски сохраняются. В легенде остаются четыре параметра.
  X трендов — даты графика; регрессии по наработке не заменяются ими.
- Прежние шкалы сохраняются, пока вмещают точки. Левая шкала расширяется
  с запасом 5 % и читаемым шагом; правая шкала ВНА расширяется вниз
  кратно 5 %. Измерения, единицы, доминирующие интервалы и отбор не меняются.
- Подписи показывают снижение N/КПД и рост b. При улучшении или нуле:
  `ΔNприв = ↓ отсутствует`, `ΔηГТУ = ↓ отсутствует`, `Δbприв = ↑ отсутствует`.
  Знаковые дельты, регрессии, таблицы и экономика сохраняются.
- `build_boundary_table` вычисляет четыре ΔP по принятым граничным точкам
  до округления и сохраняет их в attrs, без новых колонок. Новые теги —
  `period.boundary.delta.{vlo_pa,fgo_pa,fto_pa,fgo_fto_pa}`. Пропуски дают
  прочерк. Старые JSON без исходных разностей дают прочерки, не восстановление
  значений из округлённых строк. Пользовательский DOCX не редактируется.
