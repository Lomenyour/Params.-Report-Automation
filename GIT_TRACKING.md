# Что сохраняется в Git

Актуально на 29.10.2026. Исходный код приложения находится в `scr/`,
тесты — в `tests/`. Они отслеживаются Git. EXE — результат сборки этого
кода, отдельных редактируемых исходников внутри EXE нет.

## Отслеживаемые шаблоны и настройки

- `word_auto/templates/*.docx` — исходные Word-шаблоны.
- `dist_test/GTU_Report_Desktop_Test/word_auto/templates/*.docx` — рабочие
  шаблоны тестового приложения, чтобы ручные правки были видны в `git status`.
- `config/stations.json` и внешняя копия
  `dist_test/GTU_Report_Desktop_Test/config/stations.json` — справочник.
- Скрипты сборки/обновления, документация, алгоритмы, UI, тесты.

29.10.2026 по указанию пользователя актуальным признан шаблон из Desktop Test.
Он перенесён в исходную папку без изменения содержимого. Предыдущий исходный
шаблон сохранён в `archive_builds/template_sync_*/`.

Перед сборкой `sync_report_templates.ps1` сравнивает две версии с последним
согласованным хешем в `build_test/template_sync/`. Односторонняя правка
синхронизируется в обе папки с резервированием заменяемого файла. Если
изменены обе версии или нет основания выбрать одну, сборка останавливается
до явного выбора `-Prefer Source` / `-Prefer Test`. Изменения не теряются.
Копия шаблона в `_internal` обновляется как резервный ресурс сборки.
Несовпадающие внешняя/исходная копии справочника требуют согласования до сборки.

## Исключённые папки

| Группа | Папки |
|---|---|
| Данные | `data/` — никогда не добавлять, даже с `git add -f` |
| Сборки | `build/`, `dist/`, `build_import/`, `dist_import/`, `build_test/`, `archive_builds/` |
| Тестовые сборки | `dist_test/`, кроме разрешённых выше шаблонов и справочника Desktop Test |
| Отчёты | `word_auto/reports/` |
| Окружение Python | `__pycache__/`, `*.egg-info/`, `.venv/`, `venv/`, `env/`, `.pip-temp/` |
| Состояние инструментов | `.codewhale/`, `.ipynb_checkpoints/` |
| Сборка для коллеги | `app/build/`, `app/dist/`, `app/delivery/` — отдельный `app/.gitignore` |

Из `word_auto/templates/` отслеживаются только DOCX. Временные блокировки
Word `~$*.docx` исключены. Любые Excel-файлы во всём проекте исключены:
`*.xls`, `*.xlsx`, `*.xlsm`, `*.xlsb`, `*.xlt`, `*.xltx`, `*.xltm`,
`*.xla`, `*.xlam`. Также исключены `*.py[cod]`, `*.tmp`, корневые `*.spec`,
`app/*.spec`, `.DS_Store`, `Thumbs.db` и временные файлы Excel.

Пользовательские паспорта газа и коэффициенты хранятся за пределами
репозитория в LOCALAPPDATA; это данные, они в Git не попадают.

## Основная сборка

`update_main.ps1` проверяет совпадение тестового EXE с `scr/`, UI,
справочником и шаблоном. Создаёт отдельный пакет, переименовывает EXE в
`GTU_Report.exe`, сохраняет данные/отчёты основной версии, повторно проверяет
пакет и обновляет `dist/GTU_Report/`. Прежняя основная папка целиком уходит
в `archive_builds/main_before_*/GTU_Report/`. Пакет для коллеги не меняется.

В журнал `Progress.md` записываются дата, хеш реализации и результаты
проверок. Само наличие файла локально не означает, что он закоммичен:
проверка — `git status`, `git ls-files` и `git check-ignore -v`.
