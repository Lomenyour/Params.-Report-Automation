# Один период в Кировской: проверка входов — 11.11.2026

## Воспроизведённый результат

Проверены текущая `data/Кировская ТЭЦ-3 2026 3 квартал.xlsx`,
выгрузка `data/initial_data/Кировская EMB 20.09.xls`, лист Sheet1,
и текущие сохранённые назначения Кировской ГТУ-1. Расчётная книга
читается с первого листа «Данные»; коэффициенты — по её формулам.

В основной книге 9813 датированных строк до 21.06.2026 23:00 и три
недатированные строки. После объединения — 14664 даты, без повторов
и разрывов получасовой сетки. Часовой пояс источниками не указан;
метки не сдвигались. В исходных метках книги есть миллисекундная
погрешность; штатное объединение использует прежнее округление до минуты.
Нули, отрицательные измерения и выбросы не очищались.

С текущими настройками воспроизведён ровно указанный пользователем период:
**29.11.2025 13:30 — 21.06.2026 23:00**.

## Установленная причина

- C «Pатм, Па» в сохранённом маппинге основной книги имеет тип `measured`.
  В самой книге формула C2 — `O2*100+N2`; одинаковая зависимость присутствует
  в остальных строках. Наличие формулы не отменяет явно сохранённый тип.
- Канал выгрузки `CALC_12_200` («Барометрическое давление») сохранён
  как `ignored`, без назначения C.
- Поэтому C на всех **4851 новых датах** остаётся пустой. В журнале
  исполнителя воспроизводится `Нет входного значения C: 4851`.
- C нужна поправке D, а та входит в AS «Nприв». В новых строках Nприв
  недоступна; автоматический алгоритм использует именно её и пропускает NaN.
- График показывает измеренную AQ «N», которая заполнена на новых датах.
  Поэтому наличие второго участка красных точек совместимо с одним
  определённым расчётным периодом.

## Контрольное сравнение без изменения настроек пользователя

Только в памяти изменён тип C на `computed`. Остальные назначения,
выгрузка, паспорт, единицы и параметры периода сохранены:
`LOW_POWER=10 МВт`, `GAP_SIZE=288`, `WORK_CONFIRM_SIZE=48`.

Исчезли все 4851 пропуск Nприв, найдены два периода:

| Период | Начало | Конец |
| --- | --- | --- |
| 1 | 29.11.2025 13:30 | 06.08.2026 17:00 |
| 2 | 26.08.2026 16:30 | 01.10.2026 00:30 |

Для согласованного ранее использования формулы C нужно выбрать
«Поправки ГТ» → C «Pатм» → тип «Расчётный», подтвердить и запустить
перерасчёт. Альтернатива с измеренной C требует явного назначения
барометрического канала и проверки его единиц; в этом аудите её не применяли.

## Отдельное ограничение критерия останова

На измеренной мощности виден непрерывный останов 23.07.2026 19:00 —
26.08.2026 16:00 (1627 получасовых записей). После расчёта C внутри него
три строки дают Nприв выше 10 МВт при фактической мощности около 0,1 МВт.
На этих строках поправка атмосферного давления на мощность около 0,0056;
деление на малый множитель завышает Nприв. Именно эти точки дробят
останов для существующего алгоритма и сдвигают конец первого периода
до 06.08.2026. Это самостоятельное ограничение, а не причина пропажи
всех новых дат при исходном маппинге.

Отдельный тест с измеренной AQ вместо Nприв только для разметки дал:

| Период | Начало | Конец |
| --- | --- | --- |
| 1 | 29.11.2025 13:30 | 23.07.2026 18:30 |
| 2 | 26.08.2026 16:30 | 01.10.2026 00:30 |

Для физического признака работы предпочтительнее измеренная мощность;
переход меняет общие правила периодов и в приложение этим аудитом не внесён.
