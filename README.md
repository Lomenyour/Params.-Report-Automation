# Параметрический расчёт ГТУ

Расчёт по Excel-книге: периоды работы ГТУ, расходная характеристика,
сопоставимые точки TOP-10 ВНА, регрессии деградации, наработка и экономика.
Приложение показывает логи, таблицы и графики, затем позволяет сформировать
Excel и Word по одному сохранённому результату расчёта.

Состояние на 27.10.2026: новое «Рабочее пространство» использует локальные
HTML/CSS внутри десктопного Qt WebEngine и графитовую палитру ChatGPT.
Новая тестовая версия — `dist_test/GTU_Report_Desktop_Test/GTU_Report_Desktop_Test.exe`.
Прежний Tkinter-интерфейс сохранён в `scr/app.py` для сравнения и проверок.
Расчётные обработчики, импорт и экспорт используются без переписывания.
Сам EXE и входные данные в Git не хранятся.

Проверки новой версии: 40 автоматических тестов, настоящий Qt/HTML рендер
при трёх размерах окна, сценарии диалогов через WebChannel и полный расчёт
локальной книги из исходников без сохранения отчётов. Входная книга после
прогона имеет прежний SHA-256. Все 20 модулей EXE и UI-ресурсы совпадают с
исходниками; запуск упакованного EXE также проверен.

## Запуск из исходников в Windows

Проверенное окружение — Python 3.14.7 и PySide6 6.12.0. Из корня проекта:

```powershell
py -m pip install -r requirements.txt
py scr/desktop_app.py
```

В приложении выберите готовую книгу либо режим обновления данными датчиков.
Для расчётной книги используется только первый лист с именем `Данные`.
После автоматического определения периодов можно просмотреть график и
подтвердить или исправить даты. Результаты появляются во вкладках.
Выбор ТЭЦ обязателен в обоих режимах; пока в списке только СызТЭЦ.
Станция определяется по имени книги, выбор можно исправить вручную.
Три тарифа подставляются из профиля ТЭЦ и остаются редактируемыми:
газ 7,773 руб/нм³, ЭЭ 2253,66 руб/МВт·ч, себестоимость 1200 руб/МВт·ч.
Словарь датчиков также относится к выбранной ТЭЦ и номеру ГТ.
Структура справочников и их перенос в БД описаны в [config/README.md](config/README.md).
Импорт по-прежнему выбирает только получасовые записи; другую дискретность
и полный самостоятельный пересчёт производных колонок пока отложили.

Слева находятся исходная книга, ТЭЦ, режим и тарифы. Кнопка «Расчет»
закреплена внизу; после первого прогона она называется «Перерасчет».
Базовая ширина панели подготовки — 324 px. Потяните границу справа от
панели, чтобы изменить её ширину; двойной щелчок возвращает исходную.
Выбранная ширина сохраняется локально. Поле станции подписано «ТЭЦ»,
режим импорта — «Добавить выгрузку с датчиков».
Справа доступны разделы: Перепады, ВНА, Границы, ТОП-10, Деградация,
RH, Экономика. Кнопки разделов переносятся при недостатке ширины;
журнал расчёта снизу можно свернуть. Настоящее оформление находится в
`scr/desktop_ui/`; Python-адаптер `scr/desktop_controller.py` подключает
к нему прежние обработчики из `scr/app.py`. Сервер и Интернет не нужны.
Графики отображаются из памяти; масштабирование не меняет исходные Figure
и документы. Прежнее оформление Tkinter находится в `scr/ui_theme.py`.

Выбран монохромный значок турбины на графитовой основе. Он отображается
в шапке интерфейса, системном значке окна и тестовом EXE. Исходный PNG
и многоразмерный ICO находятся в `scr/desktop_ui/app-icon.*`;
прежние предложения сохранены в `design/app-icons/`.

Кнопки «Excel» и «Word» над результатами предлагают выбрать путь.
По умолчанию используется локальная папка `data/output`. Документы
автоматически после расчёта не сохраняются.

Прежний консольный запуск также доступен:

```powershell
py scr/raschet.py
```

Имя книги задаётся в `INPUT_FILE` внутри `scr/raschet.py`; локальные книги
размещаются в `data/`. Консольный сценарий запускает VNA и RH на общих данных.

## Word и сборка EXE

Для Word положите свой шаблон в
`word_auto/templates/template_mapped.docx`. Он остаётся локальным.
Список полей и правила шаблона: [TEMPLATE_MAPPING.md](word_auto/TEMPLATE_MAPPING.md).
Перед сборкой EXE папка с шаблоном также должна быть подготовлена.

```powershell
py -m pip install pyinstaller==6.22.3
powershell -NoProfile -File .\build_gui.ps1 -Name GTU_Report_Desktop_Test
```

Перед пересборкой закройте EXE с выбранным именем. Готовая папка новой версии —
`dist_test/GTU_Report_Desktop_Test/`; для запуска нужна вся соседняя папка
`_internal`, включая Qt WebEngine, локальные файлы интерфейса и ресурсы.
Без `-Name` скрипт сохраняет привычное имя `GTU_Report_Test`.
При сборке каталоги сторонней ICU (например Poppler) временно исключаются
из PATH процесса PyInstaller: Qt использует системную ICU Windows.
Это предотвращает подхват несовместимой DLL и не меняет PATH пользователя.
Скрипт обновляет только тестовую сборку. Текущие исходники находятся в `scr/`;
`app/src/` — отдельная копия для прежней поставки коллеге, её обновление
выполняется отдельно. Подробнее: [BUILD_VARIANTS.md](BUILD_VARIANTS.md).

## Проверки и документация

```powershell
py -X utf8 -m unittest discover -s tests -v
```

- [DATA_FLOW.md](DATA_FLOW.md) — текущий ход данных и алгоритмы.
- [HARD_CODED_SETTINGS.md](HARD_CODED_SETTINGS.md) — принятые ограничения.
- [Progress.md](Progress.md) — изменения, проверки и хэши коммитов.
- [agents.md](agents.md) — правила работы и исторический контекст.

В готовой книге расчёт использует уже рассчитанные колонки, включая
`ηoi_Cprop`. Полная независимая проверка всех производных колонок и переход
на их собственный построчный расчёт записаны в план; это ещё не завершено.
Подробности и выявленные ограничения описаны в `DATA_FLOW.md`.

Папка `data/`, любые Excel-файлы, локальные Word-шаблоны, готовые отчёты
и сборки приложения исключены из Git. Отметки прежней версии с шагом ВНА 1°
сохранены: `working-version-before-vna-0.1` и
`working-version-before-vna-0.1-full`.
