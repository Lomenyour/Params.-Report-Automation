# Проверка сохранения тарифов и справочных сведений ТЭЦ — 10.11.2026

Последующим поручением в тот же день справочные реквизиты подключены
к Word/JSON: `STATION_WORD_TAGS_QA_20261110.md`. Ниже сохранена проверка
первого этапа хранения тарифов и контактов.

## Область изменения

После успешного расчёта сохраняются три исходных числовых тарифа и
`station_id` завершённого снимка. Следующая книга этой ТЭЦ, выбор станции
и перезапуск подставляют последний сохранённый набор. Данные разных ГТ
одной станции используют общий тариф, как и прежде. Формулы экономики,
единицы, выбор периодов/пар, фильтры, регрессии и экспорт не менялись.
Газ — руб/нм³; ЭЭ и себестоимость — руб/МВт·ч. Перевод единиц или
автоматическое исправление введённых пользователем цен не добавлялись.

Рассмотрены три места хранения:

| Подход | Что даёт | Ограничение |
| --- | --- | --- |
| Перезапись `config/stations.json` | Один файл для каталога и цен | Разные отслеживаемые копии в исходниках/EXE; риск потери цен при следующей сборке |
| Локальные тарифы поверх базового каталога | Сохранение между книгами/перезапусками, устойчивые ключи станций; тот же порядок, что у паспортов/маппинга | Пользовательский файл нужно переносить отдельно на другой компьютер |
| База данных | История и сложные выборки | Избыточная миграция для трёх значений на станцию |

Выбран второй подход: `%LOCALAPPDATA%/GTU_Report/station_tariffs.json`.
Базовый каталог остаётся источником значений, если пользовательской записи
для станции ещё нет. Чтение не кэширует цены в экземпляре репозитория.
Сохраняются значения завершённого снимка, а не изменённые поля UI.
В снимке новые необязательные поля добавлены в конец для совместимости.
Атомарная запись использует существующий `json_store` и резервную `.bak`.
Ошибка сохранения не отменяет результаты/экспорт и видна в журнале/UI.
Повреждённый JSON не затирается; при чтении пользователь видит предупреждение
и вводит цены вручную. При повторном сохранении повреждённый файл также
остаётся целым, с предупреждением.

## Выполненные проверки

- 253 unittest прошли за 20,763 с, включая 11 новых тестов сохранения
  тарифов/контактов и прежние проверки расчётов, экспорта и импорта.
- Проверены точность float, две станции и новый экземпляр контроллера,
  смена книги/ГТ, использование завершённого снимка при изменённых полях UI.
- Отмена до запуска и ошибка расчёта не записывают тарифы. Сбой атомарной
  записи/повреждённый JSON не портят прежние данные; результат и экспорт
  остаются доступны. Неизвестные станции и некорректные числа отклоняются.
- Отдельные процессы Python записали и восстановили два синтетических
  набора тарифов с полной точностью. Реальные тарифы пользователя в этом
  тесте не перезаписывались.
- Контакты после повторного открытия корректно объединяются со своим
  каталогом; две ГТУ СызТЭЦ видят общий контакт станции. Чужие станции,
  email/телефон/одно имя и испорченные файлы проверены отдельно.
- Все тесты использовали изолированный `LOCALAPPDATA` в `build_test`.
  Реальная запись имён выполнена отдельно после проверки сопоставлений.

Локальные журналы: `build_test/station_reference_20261110/`
(`all_tests.log`, `restart_probe.log`, `import_summary.json`).

## Сборка

`build_gui.ps1` успешно заменил единственную Rotor Test на прежнем месте.
47 упакованных модулей побайтово совпали по содержимому code objects
с компиляцией исходников; HTML/CSS/JS, изображения и обе копии каталогов
совпали с исходниками. Проверка использует текущие хеши пользовательских
DOCX, а не историческую контрольную сумму прежнего шаблона.
SHA-256 обеих пользовательских копий DOCX, основной EXE, коллегиального ZIP
и `config/stations.json` не изменились. Встроенный DOCX совпал с исходным.
Пользовательские DOCX не включаются в этот коммит.

Настоящий EXE отобразил главное окно с семью вкладками результатов,
полями тарифов и отключённым экспортом до расчёта. Пустой тестовый процесс
закрыт. Ограничение нативной автоматизации: нажатие «Закрыть» вернуло
`coordinate input geometry is unavailable`, Alt+F4 —
`failed to activate captured window`. Поэтому свой пустой процесс закрыт
по проверенному PID/пути; закрытие через UI этим прогоном не подтверждено.
Сами обработчики жизненного цикла тарифов проверены тестами Qt-контроллера.

Журналы: `build.log`, `bundle.log`, `bundle_result.json`, `smoke_result.json`
в той же локальной папке. Основная и коллегиальная поставки не обновлялись.
