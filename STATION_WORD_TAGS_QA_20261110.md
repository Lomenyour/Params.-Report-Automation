# Станции и контактные лица в Word и JSON — 10.11.2026

## Поля и источник

| Тег | Значение |
| --- | --- |
| `{{ station.name }}` | Исходное имя выбранной станции |
| `{{ station.name_genitive }}` | Явно заданный родительный падеж названия |
| `{{ station.contact_persons }}` | Контактные имена через точку с запятой |
| `station.contact_names` | Список имён для цикла Jinja |

В `station.id` передаётся устойчивый ключ станции. Номер ГТУ остаётся
в `turbine.number`; пользователь подтвердил «Ижевской ТЭЦ» без добавления «-1».

Родительный падеж заполнен для всех 33 станций в `config/stations.json`
и отслеживаемой внешней копии Rotor Test. Имена, ID, компании, модели,
номера, тарифы, каналы и остальные разделы каталога после удаления нового
поля полностью совпали с прежним JSON. Распознавание файлов не изменено.
У номеров самой станции (ТЭЦ-27, Пермская ТЭЦ-9) суффикс сохранён.
Сокращения «ТЭЦ», «СызТЭЦ», название «Ситиэнерго» неизменяемы.
Правила склонения не вычисляются библиотекой и не зависят от модели ГТУ.

Контакты по `station_id` берутся из существующего частного
`%LOCALAPPDATA%/GTU_Report/station_information.json`. Несколько имён
передаются все, без выбора «главного», склонения или дополнения отчества.
Личные значения в Git не добавлялись; в тестах используются вымышленные.

## Снимок и совместимость

После расчётных таблиц считывается справочная информация выбранной ТЭЦ.
Список копируется в `report_data.station`; текстовый вариант — производное
представление списка. Повторное формирование Word и сохранение JSON
не обращаются заново к актуальному справочнику. Изменения имён после
расчёта не подменяют сохранённый снимок; имя файла не меняет ручной выбор ТЭЦ.

Если контактов нет, получаются пустая строка и список. Ошибка чтения
частного справочника видна в журнале, расчёт и остальные реквизиты остаются
доступны. Старые каталоги без `name_genitive` читаются с пустым значением.
Старые JSON без `station` отображают новые теги пустыми, включая цикл имён;
живые сведения не угадываются по имени файла или агрегата. Схема отчёта
`1.1` сохранена: добавлены необязательные совместимые реквизиты.

Пользовательский DOCX не меняется. Для новых тегов нужен новый расчёт
в обновлённой версии и размещение тегов в нужных местах шаблона.
Подробный синтаксис — `word_auto/TEMPLATE_MAPPING.md`.

## Проверки

- 260 unittest прошли за 21,624 с. Проверены все формы в каталоге,
  новый Qt-расчётный поток, отсутствующие контакты, повреждённый справочник,
  копирование списка, изменение справочника после расчёта, смена имени файла.
- JSON сохранён, повторно загружен и подставлен в проверочный DOCX:
  исходное название, родительный падеж, полный список и цикл имён.
  Проверены старый JSON и старый каталог. Неопределённых тегов не осталось.
- Статический инвентарь тегов использует актуальный `build_report_data`;
  новый объект `station` и элемент списка доступны для маппинга.
- Реальный расчёт Ижевской ГТУ-1 с выгрузкой и тремя заданными периодами
  повторён за 71,47 с. Исходные книги и пользовательские JSON сохранили SHA-256.
  Сравнение с предыдущим прогоном до изменения подтвердило точное совпадение
  всех импортированных значений, метаданных формул, таблиц, наборов графиков,
  выбранных пар, периодов и прежних полей Word. Отличия контекста ограничены
  новым `station` и временем создания. Родительный падеж — «Ижевской ТЭЦ»,
  количество контактов соответствует частному справочнику.

Локальные журналы — `build_test/station_word_tags_20261110/`:
`final_tests.log`, `real_comparison.json`; реальный снимок и его данные —
`data/diagnostics/station_word_tags_20261110/`. Эти каталоги исключены из Git.
Старая выявленная ошибка формата граничных дат Word отдельная и этим
изменением не исправлялась; прежние поля сравнивались как есть.

## Сборка

`build_gui.ps1` успешно заменил единственную Rotor Test на прежнем месте.
47 модулей в EXE совпали с текущей компиляцией исходников по содержимому
code objects; UI, внешние и встроенные каталоги также совпали. Актуальные
пользовательские DOCX сохранили SHA-256, встроенный шаблон совпал с исходным.
Основной EXE и коллегиальный ZIP сохранили SHA-256 и не обновлялись.

Настоящий EXE отобразил главное окно с семью вкладками, тарифами и кнопками
экспорта. Пустой проверочный экземпляр закрыт по проверенному PID/пути.
Нативные нажатия этим прогоном не проверялись: среда ранее не могла
активировать захваченное окно. Передача реквизитов и подстановка тегов
проверены расчётным потоком, JSON/DOCX-тестами и сравнением реальных снимков.
Журналы сборки/сверки/запуска находятся в той же папке `build_test`.
