# ТОП-10 ВНА: выбор пары и предпросмотр компрессора

Согласовано и реализовано 06.11.2026 для Qt/HTML Rotor Test.

## Работа в приложении

Внутри «ТОП-10 ВНА» доступны «Таблица» и «Графики».
В таблице переключатель «Для графика» выбирает целую пару точек.
Во вкладке графиков тот же выбор доступен в списке над графиком периода.
Выбор отдельный для каждого периода; по умолчанию используется первая пара.
Номер периода и номер пары не связаны. Изменение пары одного периода
сохраняет выбор в остальных. На графиках доступны уменьшение, увеличение
и «Вписать»: целое изображение высотой до 360 px, с центровкой.

С 12.11.2026 каждый пункт списка пар содержит «точек: N» ещё до открытия
предпросмотра. Это число измерений после полного отбора `prepare_compressor_plots`,
совпадающее с GUI/Excel-графиком, включая нулевую выборку. Поле `count`
таблицы ТОП-10 сохраняет прежний смысл — число записей окна ВНА. Числа для
списков кешируются на текущий набор данных; выбор пары не пересчитывает их,
а новый расчёт или смена входов сбрасывают кеш.

После нового расчёта, смены исходных данных или инвалидирования результата
выбор сбрасывается. Пользовательский JSON для этого не создаётся.
В Excel/Word экспортируется выбор из текущего успешного снимка расчёта.
Во время вычислений и экспорта менять пару нельзя.

## Два алгоритма с 12.11.2026

По умолчанию «Алгоритм 1 · Размах дат»: одна максимально удалённая
допустимая пара каждого окна ВНА. Сохраняются ранжирование по Δдней,
числу записей окна и Δη, удаление повторов Δдней на точности 0,001 суток
и лимит 10. Это проверено прямым полным перебором, включая пересечения окон.

«Алгоритм 2 · Число точек» выбирает одну пару каждого окна по максимальному
числу точек действующего графика после всех фильтров. Сетка 0,1 п.п., ширина
0,1–1,0 п.п., Δt ≤ 0,5 °C, Δp ≤ 5 мбар и Δη < 0,8 п.п. сохраняются.
Дополнительно разница дат пары должна быть ≥ 2/3 календарной длительности
принятого периода, а не оставшихся после фильтрации строк ВНА.
При равном числе точек предпочтительны большая разница дат, меньшая Δη
и ранний хронологический порядок. Одинаковые наборы точек графика
объединяются; полный tie разрешается узким окном и меньшей левой границей.
Разные наборы могут иметь одинаковые Δдней. Отсутствие подходящих пар
показывается для каждого периода, без ослабления порога или подмены методом 1.

Фильтры графика применяются ко всему принятому периоду; даты пары
не являются дополнительным фильтром дат. В таблице второго метода
`plot_points` — число точек графика, `count` — все строки окна ВНА.
Значения счетчиков в списке берутся общей функцией подготовки графиков.

Второй метод рассчитывается в фоне при первом выборе и кешируется в снимке.
Переключение восстанавливает отдельный выбор пар для каждого метода/периода.
Excel получает таблицы и графики активного метода, Word — его выбранную пару
в прежних полях `period.vna_top1`. Остальная аналитика сохраняется.
Новый расчёт/входы сбрасывают оба варианта. Задания старого снимка отклоняются.
Полная проверка: `VNA_ALGORITHMS_UI_QA_20261112.md`.

## Что меняется при выборе

- Предпросмотр графика КПД компрессора и степени повышения давления.
- Соответствующий график Excel, его подпись с номером пары и измерения на
  листе «Данные компрессора».
- Поля описания выбранной пары в Word: температуры, давления, ВНА, даты,
  КПД и остальные реквизиты пары. Для совместимости шаблона сохраняется
  прежнее имя поля `period.vna_top1`; его `rank` теперь показывает выбор.

Не меняются полный ТОП-10, ранги/порядок строк, даты/периоды, данные листа
«Данные», расчётные формулы и коэффициенты, границы, регрессии общей
деградации ГТУ, ΔNприв/Δbприв/ΔηГТУ, РХ и экономика.
Шаблоны Word не редактируются; используются их существующие поля.

## Общий отбор и изоляция

`selected_compressor_pairs` выбирает строку по номеру периода и рангу,
не переставляя строки ТОП-10. Ошибочный/неоднозначный ранг отклоняется.
Типы строго целочисленные: `true`, `1.0` и строки не подменяют номер периода.

`prepare_compressor_plots` сохраняет прежние фильтры: свой период, интервал
ВНА с открытой правой границей, границы температуры/давления/КПД на прежней
точности. Не меняются округление критериев и исходные численные значения.
Одна функция готовит точки и для Excel, и для GUI. При пустой выборке
предпросмотр сообщает об отсутствии измерений; другая пара не подставляется.

`CalculationSnapshot.with_compressor_pair` возвращает новый снимок с новым
выбором и независимой копией Word-контекста. Аналитические таблицы и исходные
данные сохраняются теми же объектами. Ранее переданный экспортному потоку
снимок не изменяется. Выбранные ранги находятся в
`PressureChartData.compressor_pair_ranks` и не входят в вычислительный профиль.

Предпросмотр готовится лениво при открытии «Графики», в одном фоновом
потоке. Фигуры локальны потоку; UI получает готовые PNG через отдельный
Qt-сигнал. Кеш ограничен имеющимися парами текущего расчёта и очищается при
сбросе. Запоздавший результат проверяется по идентичности снимка и не
применяется к другому выбору/новому расчёту. Линейные линии предпросмотра
строятся по тем же точкам; Excel сохраняет свои редактируемые trendline.
Никакие коэффициенты аналитических регрессий из предпросмотра не возвращаются.
