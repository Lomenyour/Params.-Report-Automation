GTU Report — приложение для расчёта

Для обычного запуска после сборки:
  dist\GTU_Report.exe

Для сборки EXE из исходников проекта:
  powershell -ExecutionPolicy Bypass -File .\build_app.ps1

Программа принимает Excel-книгу через кнопку «Выбрать Excel-файл».
Исходные книги Excel в архив передавать не нужно: пользователь выбирает свою книгу.
