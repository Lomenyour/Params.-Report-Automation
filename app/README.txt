Параметрический расчёт ГТУ

Готовый архив для передачи: delivery\GTU_Report_for_colleague.zip
Распакуйте архив полностью в обычную папку с правом записи, например в Документы.
Откройте папку GTU_Report и запустите GTU_Report.exe.
Запуск из окна архиватора не поддерживается: сначала извлеките всю папку.

Рядом с EXE обязательны _internal, config и word_auto\templates.
Они уже включены в архив. Переносите всю папку целиком.
Python устанавливать не требуется. Формирование DOCX работает без установки Word;
для просмотра готового отчёта нужна программа, открывающая DOCX.
Выберите свою расчётную Excel-книгу, ТЭЦ и ГТУ, подтвердите маппинг и периоды.
После успешного расчёта кнопки Excel и Word сохраняют отчёты в выбранное место.
Актуальный редактируемый шаблон: word_auto\templates\template_mapped.docx.

Экономика использует отдельные пороги мощности/ВНА каждого периода.
Годовые значения используют часы, прошедшие соответствующие пороги и контроль
качества. Недоступные результаты показываются прочерком, а не нулём.

Функция «Исходная книга» сохраняет книгу через установленный Microsoft Excel.
Для самого расчёта готовых значений и формирования Excel/DOCX Excel/Word не нужны.
Паспорт газа и маппинг относятся к выбранной станции и своей книге.
Личные настройки/данные автора в поставку не включены. Настройки пользователя
создаются на его компьютере в %LOCALAPPDATA%\GTU_Report.

Для разработчика: build_app.ps1 пересобирает Rotor Test, проверяет код/ресурсы
и формирует полный пакет. С ключом -UseVerifiedTest используется уже проверенная
Rotor Test. Текущие исходники находятся в scr проекта; app\src обновляется при
подготовке поставки. Архивы/EXE/данные в Git не добавляются.
