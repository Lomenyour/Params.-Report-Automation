# Варианты значка приложения

Архив первоначальных предложений по запросу пользователя, 27.10.2026.
Впоследствии пользователь выбрал другой монохромный вариант по своему
референсу: `scr/desktop_ui/app-icon.png`. Он назначен значком окна и EXE;
эти три SVG сохранены только для сравнения.

- `turbine.svg` — турбина: образ оборудования, с которым работает расчёт.
- `curve.svg` — характеристика: кривая и сопоставляемые точки измерений.
- `monogram.svg` — «ГТУ»: прямое обозначение назначения приложения.

Все варианты имеют одну графитовую основу, светлый знак и небольшой
приглушённый зелёный акцент, согласованный с интерфейсом. SVG состоят из
векторных контуров и не зависят от установленных шрифтов. Для сравнения
подготовлены PNG и Windows ICO с размерами 16, 24, 32, 48, 64, 128 и
256 px.

## Выбранный монохромный вариант

PNG — выбранный пользователем результат встроенной генерации изображения,
сохранённый без изменения рисунка, палитры и прозрачности. ICO получен
из него через Pillow (LANCZOS): 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 px.
Оба файла входят в локальные ресурсы `scr/desktop_ui/` и тестовый пакет.
Qt использует ICO для значков приложения и окна, PyInstaller — для EXE;
шапка интерфейса показывает PNG размером 32×32 CSS px.
