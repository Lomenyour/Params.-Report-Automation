# Маппинг данных расчёта в единый Word-шаблон

Документ описывает соответствие между данными расчёта и тегами в одном
универсальном Word-шаблоне.

Шаблон содержит один вариант для любого количества периодов. В JSON
передаётся список periods, а docxtpl повторяет текстовые блоки и строки
таблиц для каждого элемента этого списка.

На первом этапе подставляются текстовые значения. Таблицы и графики можно
подключать тем же способом после проверки основного текста.

## 1. Общая структура данных

Итоговый JSON, который будет сформирован после завершения расчёта и
подтверждения периодов, имеет такую структуру:

{
  "schema_version": "1.1",
  "period_count": 2,
  "tariffs": {
    "gas_rub_per_1000_nm3": "7,773",
    "electricity_rub_per_mwh": "2008,53",
    "electricity_cost_rub_per_mwh": "1100,00"
  },
  "periods": [
    {
      "number": 1,
      "ordinal_genitive": "первого",
      "ordinal_prepositional": "первом",
      "boundary": {
        "start": {},
        "end": {}
      },
      "deltas": {},
      "vna_top1": {}
    },
    {
      "number": 2,
      "ordinal_genitive": "второго",
      "ordinal_prepositional": "втором",
      "boundary": {
        "start": {},
        "end": {}
      },
      "deltas": {},
      "vna_top1": {}
    }
  ],
  "economics": {
    "total": {}
  },
  "summary": {
    "total_operating_hours": "",
    "nominal_power_hours": "",
    "nominal_vna_hours": ""
  }
}

period_count равен длине списка periods. Поле ordinal_genitive формирует
Python-программа: первого, второго, третьего, четвёртого.
Для оборотов «в первом периоде» используется поле
`ordinal_prepositional`: первом, втором, третьем, четвёртом.
Для готового оборота с предлогом используются `in_period` (В первом,
Во втором, В третьем, В четвёртом) и `degradation_period` (в первом,
во втором, в третьем, в четвёртом).

В шаблоне используется общий объект period, который появляется внутри
цикла. Поэтому для второго периода не требуется вручную писать отдельные
имена p2, для третьего — p3.

Если в одном предложении нужно обратиться к нескольким периодам напрямую,
используется индекс списка:

    Для первого периода мощность вначале = {{ periods[0].deltas.n_priv }} МВт,
    а для второго = {{ periods[1].deltas.n_priv }} МВт.

Индексация начинается с нуля: periods[0] — первый период, periods[1] —
второй, periods[2] — третий, periods[3] — четвёртый. Если период может
отсутствовать, обращение к его индексу помещается в условие:

    {%p if period_count >= 2 %}
    Для второго периода мощность вначале = {{ periods[1].deltas.n_priv }} МВт.
    {%p endif %}

## 2. Тарифы и себестоимость

`{{ current_date }}` — дата формирования Word-отчёта в локальном времени
компьютера, формат `дд.мм.гггг`. Она вычисляется при нажатии «Сформировать
Word», поэтому не зависит от даты расчёта или сохранения JSON.

Эти значения используются в любом месте шаблона напрямую:

| Тег Word | Источник | Назначение |
|---|---|---|
| {{ tariffs.gas_rub_per_1000_nm3 }} | Ввод пользователя Газ | Цена газа |
| {{ tariffs.electricity_rub_per_mwh }} | Ввод пользователя ЭЭ | Цена электроэнергии |
| {{ tariffs.electricity_cost_rub_per_mwh }} | Ввод пользователя | Себестоимость электроэнергии |

Текущий текст приказа ФАС остаётся обычным статичным текстом шаблона:

согласно приказу ФАС №1213/25 от 29.12.2025 г.

В текущей версии программы значение газа сохраняется в том виде, как оно
введено пользователем, например 7,773. Исправление единиц расчёта газа
будет отдельной задачей.

## 3. Повторяемый текст по периодам

Для повторяемого блока используются управляющие теги уровня абзаца:

{%p for period in periods %}
В начале {{ period.ordinal_genitive }} периода исследования перепад давления
на ВЛО составлял {{ period.boundary.start.vlo_pa }} Па, на ФГО+ФТО —
{{ period.boundary.start.fgo_fto_pa }} Па при положении ВНА =
{{ period.boundary.start.vna_percent }} % и активной мощности ГТУ =
{{ period.boundary.start.power_n_mw }} МВт.

В конце {{ period.ordinal_genitive }} периода исследования перепад давления
на ВЛО составлял {{ period.boundary.end.vlo_pa }} Па, на ФГО+ФТО —
{{ period.boundary.end.fgo_fto_pa }} Па при положении ВНА =
{{ period.boundary.end.vna_percent }} % и активной мощности ГТУ =
{{ period.boundary.end.power_n_mw }} МВт.
{%p endfor %}

В Word абзацы с {%p for ... %} и {%p endfor %} должны быть отдельными
абзацами. При одном периоде тело цикла появится один раз, при двух — два раза,
при трёх — три раза.

Числовые значения внутри текста нельзя оставлять захардкоженными, если они
приходят из расчёта. Например, 201 Па заменяется на
{{ period.boundary.start.vlo_pa }} Па.

Для отдельных предложений, которые перечисляют периоды поимённо, допустимы
прямые обращения periods[0], periods[1] и так далее. Такие предложения должны
иметь условия по period_count, чтобы при одном или двух периодах текст про
отсутствующие периоды не выводился.

## 5. Дельты по регрессиям

Все теги используются внутри цикла for period in periods:

| Тег Word | Колонка расчётной таблицы | Назначение |
|---|---|---|
| {{ period.deltas.n_priv }} | ΔNприв до отсечки | Снижение Nприв после отсечки улучшения, неотрицательное |
| {{ period.deltas.n_priv_percent }} | ΔNприв, % | Снижение Nприв в процентах после отсечки |
| {{ period.deltas.b_priv }} | Δbприв до отсечки | Рост bприв после отсечки улучшения, неотрицательный |
| {{ period.deltas.b_priv_percent }} | Δbприв, % | Рост bприв в процентах после отсечки |
| {{ period.deltas.eta_gtu_pp }} | Δη, п.п. | Абсолютная дельта КПД в процентных пунктах |
| {{ period.deltas.eta_gtu_percent }} | Δη, % | Относительная дельта КПД в процентах |

В повторяемом абзаце `period.deltas.show_no_degradation_text` выбирает
текст «деградация отсутствует ... расход не изменился», когда хотя бы одна
из двух дельт после отсечки равна нулю с точностью отображения (0,001).
Иначе выводится текст с числами.

## 7. Таблицы с одной строкой на период

Для повторения строк таблицы используется цикл уровня строки:

{%tr for period in periods %}
{{ period.number }} | {{ period.boundary.start.date }} | {{ period.boundary.end.date }}
{%tr endfor %}

Теги {%tr for ... %} и {%tr endfor %} должны размещаться в отдельных
строках таблицы. Конкретные поля в строке берутся из разделов выше.

## 9. Форматы

- Даты: дд-мм-гггг чч:мм.
- Десятичный разделитель: запятая.
- Проценты дельт `Nприв` и `bприв`: ровно два знака после запятой.
- Денежные значения: два знака после запятой, если для конкретного места
  шаблона не задан другой формат.
- Пустое или отсутствующее значение: —.
- Математические операции выполняются в Python до передачи данных в Word.

## 10. Что нужно размечать в Word

1. Тарифы и экономику — обычными тегами {{ ... }}.
2. Повторяемый текст по периодам — между {%p for period in periods %} и
   {%p endfor %}.
3. Повторяемые строки таблиц — между {%tr for period in periods %} и
   {%tr endfor %}.
4. Внутри цикла использовать period.boundary..., period.deltas... и
   period.vna_top1....
5. Числовые значения, которые меняются после расчёта, заменить тегами.

## 11. Текущий статус

- Один универсальный Word-шаблон: согласован.
- Количество блоков текста: определяется длиной periods.
- Слово «первого/второго/третьего/четвёртого»: передаётся в
  period.ordinal_genitive.
- Для прямых перечислений периодов используются periods[0] ... periods[3]
  вместе с условиями по period_count.
- Маппинг под periods[]: описан в этом документе.
- scr/reporting.py формирует JSON после финального выбора периодов и
  перезаписывает `data/report_runs/latest.json`.
- В GUI добавлена кнопка «Сформировать Word», которая использует
  `word_auto/templates/template_mapped.docx` и сохраняет
  `word_auto/reports/report.docx`.
